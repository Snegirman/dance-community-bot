# Изменение времени публикации через бота

Запрос владельца: разрешить редактирование `WEEKLY_PUBLICATION_TIME` в интерфейсе
бота. Изменение дополняет задачу 7, не запускает задачи 8–9 основного плана.

## Сценарий

`/settings` показывает время по Москве и кнопки «Изменить время» и «Отключить
автопубликацию». После первой кнопки бот просит ответить на сообщение временем
`ЧЧ:ММ`. Корректный ответ сохраняется сразу; неверный ввод не меняет настройку.
Настройка доступна только числовому ID владельца в личном чате.

Рассмотрены команда с аргументом и кнопки с ответом на запрос. Исполнитель выбрал
кнопки, чтобы владелец мог найти настройку без запоминания синтаксиса команды.
Выбор интерфейса предложен владельцу в чате; отдельных требований к нему не дано.

## Хранение и применение

Время хранится в SQLite, сохраняется после перезапуска и используется планировщиком
и `/status` без перезапуска. Значение окружения служит только начальным значением
при инициализации новой базы. Явное отключение не заменяется значением
окружения при следующем запуске. Выбранное время не записывается в `.env`.

Ревизия защищает от старых кнопок, старых ответов и повторной доставки. Привязка
запроса времени к сообщению бота сохраняется в базе. Обычные события и ответы
на карточки продолжают обрабатываться прежним сценарием.

Изменение влияет на ближайший будущий понедельничный срок. Уже отправленный
или начатый выпуск не повторяется. Если новое время уже прошло, автоматической
отправки задним числом нет. Старое уведомление о пропуске или пустой неделе
не блокирует новый будущий срок после изменения настройки. Повтор того же значения
не создаёт новую ревизию. Смена настройки не считается пересечением её нового срока.

## Границы

Только Python 3.13, существующие aiogram/SQLite, без новых зависимостей. Зона
`Europe/Moscow` фиксирована, время по умолчанию отсутствует. ID группы остаётся
в окружении. Схема новой базы обновляется без миграции старых баз по правилам проекта.
Пользовательские сообщения — по-русски. Код и тесты пишет `luna_worker`, главный
агент проводит ревью и исправляет ошибки. Реальные Telegram-запросы не нужны.
