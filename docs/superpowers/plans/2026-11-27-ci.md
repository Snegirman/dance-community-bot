# Проверки GitHub Actions перед автодеплоем

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development; реализацию выполняет `luna_worker`, ревью и исправления — главный агент согласно AGENTS.md.

**Goal:** Проверять PR в `main` и изменения `main` до подключения автодеплоя.

**Architecture:** Одно задание GitHub Actions на Ubuntu 24.04 запускает существующие
проверки и сборку пакета. Серверная часть зависит от разрешённого способа
управления VPS и будет добавлена после его проверки.

**Tech Stack:** Python 3.13, uv 0.13.7, pytest, Ruff, GitHub Actions.

**Spec:** Запрос владельца на CI/CD из `main` и существующие проверки
в [README](../../../README.md#быстрый-старт).

## Ограничения

- Секреты Telegram и доступ к VPS не нужны для CI.
- Версия Python читается из `.python-version`; зависимости — из `uv.lock`.
- Ошибка проверки прерывает задание; несоответствие lock-файла считается ошибкой.
- Изменения ограничены workflow и его документацией; прикладной код не меняется.
- Actions закреплены полными SHA, токен имеет только `contents: read`.

## Задача 1: workflow и документация

Файлы: создать `.github/workflows/ci.yml`, добавить раздел CI в `README.md`.

- [x] Запускать `push` в `main`, `pull_request` в `main` и `workflow_dispatch`.
- [x] Использовать `ubuntu-24.04`, таймаут 15 минут и отмену устаревших CI-запусков
  одной ветки/PR через `concurrency`.
- [x] Checkout без сохранения credentials; установка uv 0.13.7 и Python из
  `.python-version` командой `uv python install`.
- [x] Последовательно выполнить `uv sync --locked`, `uv run --locked pytest -q`,
  `uv run --locked ruff check .`, `uv run --locked ruff format --check .`,
  `uv build --no-sources`.
- [x] В README объяснить триггеры, проверки и необходимость отправить workflow
  в GitHub; явно отделить подготовленный CI от ещё не настроенного автодеплоя.
- [x] Главному агенту проверить YAML, триггеры, SHA Actions и полный diff;
  выполнить команды локально и диагностику редактора.

## Результат локальной проверки

- Зависимости синхронизированы через `uv sync --locked` из локального кеша.
- `pytest -q`: 442 теста прошли; Ruff lint прошёл; Ruff format подтвердил 68 файлов.
- `uv build --no-sources`: собраны wheel и sdist. Содержимое архивов проверено:
  секреты, база и локальный кеш не включены.
- YAML разобран успешно; полные SHA и поддерживаемые inputs Actions проверены
  по исходникам официальных репозиториев.
- Диагностика редактора недоступна: инструмент вернул ошибку. Локальная проверка
  YAML не заменяет запуск workflow в GitHub.

## Серверная часть

Владелец указал существующий VPS и приватный репозиторий его эксплуатации.
Сведения оттуда используются только для выбора совместимого способа размещения;
приватные конфигурации и материалы не переносятся в публичный репозиторий бота.
Автодеплой и серверные изменения не считаются выполненными по локальным проверкам CI.
