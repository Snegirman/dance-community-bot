# Повторная отправка недельного выпуска — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Владелец повторно отправляет актуальный выпуск текущей недели через `/republish`.

**Architecture:** Повторы хранятся отдельно от исходного выпуска в общем журнале
публикаций. Отправка, подтверждения и восстановление используют существующие
механизмы; каждый новый повтор собирает актуальные данные каталога. Снимок
фиксируется после начала отправки, как у обычного выпуска.

**Tech Stack:** Python 3.13, aiogram 3, SQLite, uv, pytest, Ruff; без новых зависимостей.

**Spec:** [Повторная отправка](../specs/2026-11-13-repeat-weekly-publication-design.md).

## Global Constraints

- Только Python; все пользовательские сообщения на русском.
- Текущая неделя определяется через `ZoneInfo("Europe/Moscow")`.
- Текст, подписи, афиши и порядок частей собираются из актуального подтверждённого каталога.
- До начала отправки ревизия каталога проверяется; после начала снимок неизменен.
- Подтверждение владельцем обязательно; сообщения и callback проверяют ID и личный чат.
- Повтор команды/callback и перезапуск не создают дополнительную отправку.
- Не добавлять зависимости, `typing.cast`, необоснованный `Any`, конфигурационные опции.
- Код и тесты пишет `luna_worker`; главный агент проводит ревью и исправляет ошибки.

## Review Focus

- Каталог изменился до предпросмотра: отправляется обновлённый выпуск. Изменился
  после предпросмотра: нужен новый предпросмотр и подтверждение, старый не отправляется.
- Та же команда повторно доставлена после успешного повтора: новая отправка не создаётся.
- Другая команда присоединилась к незавершённому повтору: её повторная доставка
  после завершения тоже не создаёт отправку.
- Группа изменена, callback старый либо автор посторонний: сетевой отправки нет.
- Части уже доставлены перед сбоем: восстановление повторяет только нужные части.
- После отмены всех событий неделя пуста: сообщений в группе не появляется.

## Результат 13.11.2026

`luna_worker` реализовал задачу; главный агент проверил обработчики, транзакции,
индексы и тесты. После ревью исправлены подсказки для завершённого/отклонённого
повтора и сравнение исходного журнала в тесте восстановления. Новые зависимости
не добавлены. SQLite использует схему 8; миграции старых баз отсутствуют.

предпросмотра, защита от повторов команды/кнопки, московская граница недели,
пустая неделя и отсутствующие настройки/исходник, доступ владельца, смена группы,
перезапуск и восстановление частей после неизвестной доставки. Исходные части
и снимок проверяются на неизменность; стандартные тесты планировщика тоже проходят.
