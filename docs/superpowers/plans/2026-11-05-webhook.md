# Переход на webhook: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Правила проекта уточняют распределение: код и тесты пишет `luna_worker`, главный агент проводит ревью и исправляет замечания.

**Goal:** заменить polling входящими webhook-запросами Telegram.

**Architecture:** aiohttp слушает loopback за HTTPS-прокси или локальным
туннелем. aiogram проверяет секрет и передаёт сообщения текущему диспетчеру.

**Tech Stack:** Python 3.13, uv, aiogram 3, aiohttp, Pydantic, pytest, Ruff.

**Spec:** [Переход на webhook](../specs/2026-11-05-webhook-design.md).

## Global Constraints

- Не менять логику команд и ограничения доступа владельца.
- Не использовать реальные ключи и Telegram в автоматических проверках.
- Не удалять существующие незакоммиченные изменения и не коммитить их.
- Локальный bind `127.0.0.1`, порт по умолчанию 8080.
- Накопленные updates сохраняются; раннее фоновое подтверждение отключено.

## Review Focus

- Отсутствующий/неверный секрет не должен достигать обработчиков.
- Ошибка регистрации webhook должна закрывать HTTP-сессию бота.
- Ошибка запуска и остановка приложения должны освобождать ресурсы.
- Полный URL должен соответствовать зарегистрированному маршруту.
- Конфигурационные ошибки и журналы не должны раскрывать секреты.
