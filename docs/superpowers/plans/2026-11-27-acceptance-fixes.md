# Правки по результатам живой приёмки

> **For agentic workers:** использовать `superpowers:subagent-driven-development`;
> код и тесты пишет `luna_worker`, ревью и исправления выполняет главный агент
> согласно AGENTS.md. Пользователь поручил сразу выполнить зафиксированные правки.

**Goal:** выполнить список доработок от 26.11.2026 из README.

**Architecture:** сохранить aiogram, SQLite и существующие привязки действий.
Отделить окончательный отказ неверного ввода от восстанавливаемого сбоя загрузки.
Форматирование Telegram не должно менять пользовательские данные и снимки уже
начатых выпусков; применить entities к исходному тексту с учётом UTF-16.

**Tech Stack:** Python 3.13, uv, aiogram 3, SQLite, pytest, Ruff.

**Spec:** [согласованные правки](../../../README.md#следующие-этапы),
[основная спецификация](../specs/2026-11-04-structured-input-design.md).
Новый сценарий отказа неверного ввода заменяет прежнее восстановление через
карточки источников; это изменение владелец согласовал во время приёмки.

## Ограничения и решения

- Не менять схему рабочей базы без необходимости; не удалять существующие данные.
- Сохранить внутренние версии, ревизии и историю, необходимые для устаревших
  действий, исключений расписания и восстановления публикаций. Убрать их
  технические номера из пользовательских сообщений.
- Неверный шаблон не создаёт карточку и не скачивает новую афишу. Ошибка не
  появляется в `/events` как восстанавливаемая карточка. Повторная доставка
  не должна превращать отвергнутое сообщение в событие.
- Неверная правка сохраняет прежнее состояние и афишу. Бот просит повторить
  полный шаблон вместе с новой афишей, если она нужна.
- Сбой скачивания при правильном шаблоне остаётся восстанавливаемым.
- Меню «Расписание» показывает недели с диапазонами дат и позволяет двигаться
  назад/вперёд. Существующие команды и проверка доступа сохраняются.
- Скилл готовит текст для владельца, не добавляет нейросеть в бота и не отправляет
  сообщения в Telegram самостоятельно.

## Проверить при ревью

1. Неверная подпись фотографии и неверная правка серии не скачивают файл.
2. Повтор сообщения, перезапуск и старые кнопки сохраняют защиту от дублей.
3. Длинные тарифы, emoji и текст с `<`, `>`, `&` не теряются и не становятся разметкой.
4. Превью с афишей сохраняет действия и привязку всех текстовых частей.
5. Меню доступно только владельцу в личном чате; даты считаются по Москве.
